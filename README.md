# 🎓 AI Student StudyMate

AI Student StudyMate is an AI-powered learning platform designed to help students study more efficiently. It provides intelligent tools for asking questions, summarizing notes, generating quizzes, creating flashcards, and planning study sessions in one easy-to-use application.

## 🌐 Live Demo

**Website:** https://ai-student-studymate.netlify.app/

---

# 📚 Problem It Solves

Many students struggle with understanding complex topics, organizing study materials, and preparing for exams. AI Student StudyMate acts as a personal AI tutor that makes studying easier, faster, and more effective.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/AI-Student-StudyMate.git
```

Go to the project folder

```bash
cd AI-Student-StudyMate
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
